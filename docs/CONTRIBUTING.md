# Contributing to EST3LAMY

We welcome contributions to the EST3LAMY digital investigation platform. Follow these standards.

## Setup

```bash
git clone https://github.com/eraasoft-train/EST3LAMY-Eg-digital-bank-F.git
cd EST3LAMY-Eg-digital-bank-F
npm install
npm run dev
```

## Code Style

- TypeScript with strict mode
- Tailwind CSS for styling
- Functional components with hooks
- Arabic-first content, bilingual data where applicable

## Pull Requests

- Branch from `main`
- Describe what changed and why
- Ensure the build passes: `npm run build`
