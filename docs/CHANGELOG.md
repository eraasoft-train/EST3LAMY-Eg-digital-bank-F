# Changelog

All notable changes to the Finovia Digital Banking project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-03-28

### Added
- Initial architecture release for the Finovia Banking Platform.
- Next.js 14 App Router integration.
- Responsive landing page sections (Hero, Accounts, Loans, Security).
- Interactivity via Framer Motion.
- Design system based on Tailwind CSS and Radix UI.
- Dark mode support using `next-themes`.
- Comprehensive project documentation in `docs/`.
- CI/CD workflow configurations for GitHub Actions.

### Technical Foundation
- Next.js 14.2.16
- React 18
- TypeScript 5
- Tailwind CSS 3.3
- Radix UI Primitives
- Framer Motion
- Lucide React Icons
