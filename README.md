## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+
- npm 9+ (or pnpm / yarn)

### Installation

```bash
# Clone the repository
git clone https://github.com/Mostafa-SAID7/Finovia.git
cd Finovia

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Available Scripts

```bash
npm run dev        # Start development server (hot reload)
npm run build      # Build for production
npm run preview    # Preview production build locally
npm run typecheck  # Run TypeScript type checking
```

## 📁 Project Structure

```
finovia/
├── public/               # Static assets (favicon, og image)
├── src/
│   ├── components/
│   │   ├── layout/       # Navbar, Footer, PageLoader
│   │   ├── sections/     # Hero, Dashboard, Accounts, Security…
│   │   └── ui/           # Reusable Radix/shadcn components
│   ├── data/             # Static content & typed data
│   ├── hooks/            # Custom React hooks
│   ├── lib/              # Utility functions (cn, etc.)
│   ├── pages/            # Route-level page components
│   ├── App.tsx           # Root app with routing & providers
│   ├── main.tsx          # Entry point
│   └── index.css         # Global styles + Tailwind config
├── index.html            # HTML entry with SEO meta
├── vite.config.ts        # Vite configuration
├── tsconfig.json         # TypeScript configuration
└── package.json          # Dependencies & scripts
```
