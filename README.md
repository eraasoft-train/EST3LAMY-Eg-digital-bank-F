## 📌 نبذة عن المنصة (Overview)

**استعلامي (EST3LAMY)** منصة تقنية مالية (Fintech) مصرية رائدة تُرقمن دورة حياة التحقيق الميداني والتحقق من العملاء بالكامل — من استلام طلب الاستعلام من المؤسسة المالية، مروراً بالتوزيع الذكي للحالات على الباحثين الميدانيين وتتبع مواقعهم الجغرافية بالـ GPS، وجمع الأدلة والصور الموثقة عبر تطبيق الهاتف المحمول، ومراجعة ضبط الجودة (QC)، وحتى تسليم التقرير الائتماني النهائي المعتمد للمؤسسة.

**المجموعة الأم:** [Fair Solutions for Consulting](https://fidb-islamic.com/)

## 🌟 القدرات والمميزات الرئيسية (Key Capabilities)

| القدرة | الوصف |
|--------|-------|
| **إدارة الحالات الذكية** | استلام وتوزيع وجدولة طلبات الاستعلام الميداني آلياً حسب النطاق الجغرافي |
| **تطبيق المحقق الميداني** | تطبيق هاتف ذكي يعمل بنظام (Offline-First) لجمع البيانات حتى في غياب الإنترنت |
| **تتبع GPS والتحقق الجغرافي** | محرك Geofencing يثبت التواجد الفعلي للباحث في العنوان المذكور لمنع الزيارات الوهمية |
| **جمع الأدلة الرقمية** | التقاط فوتوغرافي موثق للبطاقات، العقارات، عدادات المرافق، واستمارات المقابلة |
| **محرك ضبط الجودة (QC)** | تدقيق آلي وبشري لاكتمال المستندات وصحة البيانات قبل اعتماد التقرير |
| **تقارير ائتمانية موثقة** | توليد تقارير PDF رقمية مشفرة قابلة للتسليم الفوري لقطاع الائتمان |
| **لوحات التحليل التشغيلي** | متابعة مباشرة لاتفاقيات مستوى الخدمة (SLAs) ومتوسط وقت الإنجاز (TAT) |
| **دعم ثنائي اللغة (RTL/LTR)** | واجهة متكاملة باللغتين العربية (RTL) والإنجليزية (LTR) |

## 🧭 الصفحات والمسارات (Routes)

- **`/`** — الصفحة الرئيسية (Hero، ميزات المنصة، سير العمل، المعاينة التشغيلية)
- **`/solutions`** — باقات وحلول الخدمة للمؤسسات المالية (الأساسية، المتقدمة، المؤسسية)
- **`/how-it-works`** — دليل المراحل الثماني لدورة حياة الحالة الاستعلامية
- **`/technology`** — البنية التحتية، تطبيق الجوال، خوارزميات التتبع الجغرافي، والتشفير
- **`/industries`** — القطاعات المخدومة (البنوك، التمويل الاستهلاكي، التأجير، التمويل العقاري...)
- **`/dashboard`** — **بوابة العمليات الميدانية التفاعلية (محاكاة حية لإدارة الحالات والباحثين وضبط الجودة)**
- **`/about`** — قصة المنصة، الرؤية والرسالة، وسياق مجموعة Fair Solutions
- **`/contact`** — نموذج التواصل والشراكة المؤسسية
- **`/privacy`** — سياسة الخصوصية وسرية البيانات المصرفية
- **`/terms`** — الشروط والأحكام واتفاقية مستوى الخدمة (SLA)

## 💻 التقنيات المستخدمة (Tech Stack)

- **React 19** + **TypeScript** + **Vite 6**
- **Tailwind CSS v4** + **tw-animate-css** — تصميم عصري متجاوب بنظام تصميم مخصص
- **Radix UI** — مكونات واجهة قابلة للوصول بالكامل (Accessible UI)
- **Framer Motion** — رسوم وحركات تفاعلية سلسة
- **Wouter** — توجيه خفيف الوزن وسريع
- **TanStack Query v5** — إدارة ومزامنة الحالة
- **Lucide React** — أيقونات متجهة عالية الدقة
- **Recharts** — مخططات بيانية تشغيلية
- **Cairo & Inter Fonts** — خطوط متناسقة للعربية والإنجليزية

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# 1. استنساخ المستودع
git clone https://github.com/eraasoft-train/EST3LAMY-Eg-digital-bank-F.git
cd EST3LAMY-Eg-digital-bank-F

# 2. تثبيت الحزم
npm install --legacy-peer-deps

# 3. تشغيل خادم التطوير
npm run dev

# 4. فحص TypeScript والتأكد من خلو الأخطاء
npm run lint

# 5. بناء نسخة الإنتاج
npm run build
```

## 🛡️ الأمان والامتثال (Security & Compliance)

تلتزم المنصة بتشفير البيانات الحساسة (TLS 1.3 للنقل، و AES-256 للتخزين) مع الامتثال لضوابط حماية البيانات وحفظ السجلات وسرية المعاملات الائتمانية المعمول بها في جمهورية مصر العربية.
