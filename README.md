# استعلامي — EST3LAMY Digital Investigation Platform

> منصة رقمية متكاملة لرقمنة عملية التحقيق الميداني والتحقق من العملاء للمؤسسات المالية في مصر.

[🌐 الموقع الرسمي](https://est3lamy.com) · [📖 التوثيق](./docs) · [🤝 المساهمة](./docs/CONTRIBUTING.md)

---

## نظرة عامة

**استعلامي (EST3LAMY)** منصة فينتك مصرية تُرقمن عملية التحقيق الميداني بالكامل — من استلام طلب التحقيق من المؤسسة المالية، مروراً بتوزيع الحالات على الباحثين الميدانيين وتتبع مواقعهم، وجمع الأدلة والصور، وحتى تسليم التقرير الموثق.

**الشركة الأم:** [Fair Solutions for Consulting](https://fidb-islamic.com/)

## التقنيات المستخدمة

- **React 19** + **TypeScript** + **Vite 6**
- **Tailwind CSS v4** — نظام تصميم متكامل
- **Radix UI** — مكونات واجهة قابلة للوصول
- **Framer Motion** — رسوم متحركة سلسة
- **Wouter** — توجيه خفيف الوزن
- **TanStack Query** — إدارة حالة الخادم
- **Lucide React** — أيقونات SVG
- **Recharts** — مخططات بيانية

## تشغيل المشروع محلياً

```bash
# استنساخ المستودع
git clone https://github.com/eraasoft-train/EST3LAMY-Eg-digital-bank-F.git
cd EST3LAMY-Eg-digital-bank-F

# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء للإنتاج
npm run build
```
